Aim:
To learn about HTML div elements, attributes and fixing errors in HTML code.

Introduction:
HTML provides different elements to structure and organize content on a webpage.

Theory:
The <div> tag is a container used to group HTML elements. It helps organize webpage sections and apply CSS styles.
HTML attributes provide additional information about elements. For example, id gives a unique identity, while class is used to group elements for styling.
Fixing errors in HTML helps display the webpage correctly in a browser.

Procedure:
Create an HTML file.
Add div elements to group content.
Use attributes like id and class
Check and correct HTML errors.
Run the file in a browser.

Result:
Successfully learned to use div elements, HTML attributes and fix basic HTML errors.
