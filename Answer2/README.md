Aim:
To learn how to push a local Git repository to GitHub and clone an existing remote repository.

Introduction:
Git is a version control system used to manage and track changes in project files. GitHub is an online platform where developers can store and share their Git repositories.

Theory:s
Pushing is the process of uploading local commits from a computer to a remote repository on GitHub. It helps keep the online repository updated with the latest changes.
Cloning is the process of creating a local copy of a remote repository. It downloads the project files and their Git history to the computer.
Both operations are important for sharing projects, maintaining backups and working collaboratively with other developers.

Procedur:
Create a repository on GitHub.
Open the local project folder in VS Code.
Connect the local repository to GitHub using the remote URL.
Add and commit the project files.
Use the push command to upload changes.
Copy the repository URL from GitHub.
Use the clone command to download the repository.

Result:
Successfully learned how to push a local repository to GitHub and clone a remote repository to a local computer.
