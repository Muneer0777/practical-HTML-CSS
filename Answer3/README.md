Aim:
To create and run a basic HTML page using HTML.

Introduction:
HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

Theory:
HTML uses different tags to display text, headings, paragraphs, images and links on a webpage. Every HTML document generally contains <html>, <head> and <body> tags.
The browser reads HTML code and displays the content as a webpage.

Procedure:
Open VS Code.
Create a new file named index.html.
Write basic HTML code.
Save the file.
Open it in a web browser.

Result:
Successfully created and displayed my first HTML page.
